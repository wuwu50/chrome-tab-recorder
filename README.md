# 分頁影音錄影機

Chrome 116+ 擴充功能：指定分頁影音錄製、獨立繁體中文控制視窗、本機儲存與可設定更新來源。

## 下載與安裝

Windows 10／11：到 [GitHub Releases](https://github.com/wuwu50/chrome-tab-recorder/releases/latest) 下載 `ChromeTabRecorder-版本-Setup.exe`。安裝後開啟桌面或開始功能表捷徑，使用引導介面開啟 Chrome、複製擴充功能資料夾路徑，完成「載入未封裝項目」。不需要系統管理員權限。

EXE 負責安裝檔案、建立捷徑與引導 Chrome 啟用；影音錄製仍由 Chrome 擴充功能執行。第一次啟用與升級後重新載入需要使用者操作。解除安裝前，先在 Chrome 移除擴充功能。

也保留 ZIP 手動安裝：解壓縮，在 chrome://extensions 開啟開發人員模式，載入包含 manifest.json 的資料夾。

在目標網頁點擴充功能圖示 → 開啟獨立控制視窗 → 開始錄影。背景錄影不擷取其他程式、其他分頁或麥克風音訊。最小化後畫面是否持續更新仍取決於網站與 Chrome，請先短錄驗證。

完整操作與限制請看 [使用說明](extension/使用說明.md)。錄影 UI 是獨立 Chrome 控制視窗，安裝引導則是原生 Windows 視窗。

## 程式內更新

v1.6.0 的 Windows EXE 安裝版支援確認後自動下載安裝。桌面捷徑開啟的視窗按「檢查更新並安裝」，或從 Chrome 錄影控制視窗按「確認更新並自動安裝」。會自動使用原本安裝目錄；不需要選擇下載檔案位置。更新先驗證官方安裝包 SHA-256，再啟動只有進度畫面的安裝流程。下載失敗或驗證不符不執行安裝，保留原版。

舊版需先手動安裝 v1.6.0 一次。請先停止錄影並儲存；安裝後 Chrome 擴充功能仍需重新載入。ZIP 版沒有註冊 Windows 更新器，請使用 EXE 安裝版。

首次 Release 成功後，Actions 會在 main 分支建立 `version.json`。程式預設已設定此來源：

`https://raw.githubusercontent.com/wuwu50/chrome-tab-recorder/main/version.json`

按「檢查更新」並允許 Chrome 連線即可。EXE 安裝版確認更新後自動安裝；ZIP 版手動替換。安裝後重新載入；更新前先停止錄影並儲存。原先已手動設定或清空的來源會保留；必要時在「設定更新來源」改回上方網址。

## 自動發布

把此資料夾內容上傳到專用儲存庫的 main 分支；`.github/workflows/release.yml` 會測試、產生 ZIP、發布 Release，最後寫入線上版本資訊。只有 Release 建立成功後才發布 version.json。

後续修改需提高 `extension/manifest.json` 的版本，並更新 `RELEASE_NOTES.md`。相同版本不覆蓋既有 Release；若發布失敗，請先查 Actions 的錯誤，再處理。

## 本機驗證

需要 Node.js 24，不需安裝 npm 依賴：

```
node tests/test-recorder.cjs
node tests/test-updates.cjs
```

這些是模擬流程測試；不代表已驗證所有網站的實際影音與最小化行為。

## 長時間錄影與中斷取回

v1.7.0 逐段保存錄影、限制待寫入資料並檢查估計暫存配額。重新開啟控制視窗可嘗試儲存未完成的片段；不保證意外中斷的 MP4 可播放，也無法保證取回舊版暫存。120 FPS 仍可選；長錄建議先測試 60 FPS。遇到問題請按「匯出錯誤紀錄」。詳見使用說明。

## v1.8.0 長錄自動分段

每次錄影仍使用指定分頁的同一個影音擷取串流，維持選定的畫質、FPS、音訊隔離與靜音處理。MP4 編碼器在每段約 1 GiB 或 5 分鐘時停止並重新建立，依資料事件抵達時間切換，實際段落可能略大或略長。這是為了避開 Chromium 155 的 MP4 OutputPositionTracker 使用 uint32_t 累計位置、超過 4 GiB 時觸發 CHECK 的限制：
https://github.com/chromium/chromium/blob/155.0.8059.39/media/muxers/output_position_tracker.cc

同一次長錄產生多個獨立 MP4，例如「分頁錄影-時間-第001段.mp4」「第002段.mp4」。v1.11.0 起停止後會重新封裝合併成一部 MP4，不會直接串接獨立 MP4 的檔案位元組。切換編碼器、完成前段暫存與啟動下一段之間可能有短暫影音缺口，無法保證無縫錄製。合併會沿用原有影音資料，不重新壓縮。

停止後預設合併並儲存一部 MP4。設定儲存資料夾後直接寫入；未設定時只詢問一次存檔位置。按「改用分段儲存」才會輸出各段 MP4。取消或失敗時保留尚未儲存片段，重新開啟可繼續；只有所有段落下載完成或明確刪除時才清除暫存。v1.7.0 的舊暫存仍支援嘗試儲存，但不保證中斷的尾段可播放。

每段組合時需要該段 MP4 的額外暫存空間；未下載的所有原始片段會保留到全部下載完成。120 FPS 仍是擷取／編碼目標，不保證硬體與來源每秒都產生 120 個不同畫面。

本次驗證包含門檻切換、最後資料寫入、同一擷取串流、下載取消與重開續存、快速下載完成競態，以及實際 Chrome 以縮短切換門檻錄製多段可播放的 1080p MP4。短測試不代表已驗證使用者網站長錄或無縫切換。

## v1.9.0 更新並自動安裝

Windows EXE 安裝版使用官方更新來源時，主按鈕「更新並自動安裝」直接開啟已安裝的更新器。更新器檢查版本，確認後自行下載安裝包、驗證 SHA-256 並以無安裝位置選擇頁的更新流程安裝到原本目錄。不經 Chrome 的下載另存新檔，也不需要自行找 EXE。

更新專用視窗不再顯示第一次啟用 Chrome 擴充功能的資料夾操作。Chrome 若詢問是否開啟更新器，請允許。安裝完成後，在原有擴充功能卡片按「重新載入」即可，不要再次按「載入未封裝項目」。首次啟用仍須完成 Chrome 的資料夾選擇。

手動下載移到「設定更新來源／手動下載」內。自訂來源仍只做版本檢查與手動下載；原生自動更新器只安裝本專案官方 GitHub 安裝包。ZIP 版未安裝 Windows 更新器，需先安裝 EXE。

舊版目前可直接從桌面／開始功能表的錄影機按「檢查更新並安裝」升級，不需要在 Chrome 按「下載新版」。更新前先停止錄影並儲存所有暫存。


## 指定資料夾自動存 MP4（v1.10.0）

在錄影控制視窗的「儲存資料夾」按「選擇／更換資料夾」，選取實際要存放影片的資料夾並允許存取。設定會記住，下次錄影不需重新選擇。停止後所有段落會依序直接寫入該資料夾，檔名固定為 .mp4。

Chrome 僅提供資料夾名稱，完整位置請從資料夾選擇視窗確認。重新啟動或權限失效時，按「允許存取」；若資料夾不存在、磁碟滿或權限不足，暫存不會刪除，可重新授權／更換資料夾後按「重新儲存影片」。同名影片自動加上編號。未設定資料夾時仍使用原本 Chrome 下載方式。


## 停止後自動合併（v1.11.0）

錄製時仍每約 1 GB 或 5 分鐘保護性分段，避免 Chrome MP4 編碼器累積超過 4 GB。按「停止、合併並儲存」後，畫面會顯示合併進度，最後儲存一部完整 MP4 到已選定的資料夾；未指定資料夾則顯示一次存檔對話框。

合併在本機逐步讀寫，不重新壓縮，不會上傳影片，無需另外安裝工具。需保留原始片段和合併後影片所需的磁碟空間，請保持 Chrome 開啟直到儲存完成。切換段落原有的短暫缺口無法補回。

合併或儲存失敗會保留片段，可按「重新儲存影片」。如果尾段中斷、編碼資訊不同或磁碟空間不足，可按「改用分段儲存」，依序輸出原始 MP4 段落。已完成的分段不會重新儲存。合併檔成功儲存前，不會刪除原始片段。

使用隨程式附帶的 Mediabunny 1.61.3（MPL-2.0）；授權與原始碼來源見 extension/vendor/NOTICE.md。


## 加速存檔（v1.12.0）

已選擇資料夾時，停止後直接將合併 MP4 寫入目的資料夾，省去整部暫存影片的額外複製。單段與分段輸出同樣直接寫入。合併不再使用可能受 Chrome 背景節流的計時器等待。原始片段仍保留到輸出成功，失敗可重試。未選擇資料夾時仍需先完成暫存影片，再透過 Chrome 下載存檔。實際耗時取決於影片大小、CPU、磁碟速度與背景負載。


## 邊存檔邊開始下一次錄影（v1.13.0）

按「停止並背景儲存」後，程式先停止擷取並收完最後資料，再立即開放開始下一次錄影，不必等待前一部合併完成。前一部會列在「背景儲存」，依序合併並存成一部 MP4；錄影與各部暫存資料獨立，避免覆蓋或互相停止音訊。可操作其他程式或最小化 Chrome，但須保持 Chrome 開啟。背景儲存與新錄影共用 CPU／磁碟資源，實際速度仍取決於硬體。

失敗的影片會單獨列出，可按重新儲存、分段儲存或刪除此暫存；刪除只影響選定影片。重新啟動後會列出所有找回的待存影片，舊版本暫存也支援救援。錄影或背景工作未完成時不能安裝更新。

空間警告表示 Chrome 暫存配額或所在磁碟可用空間不足，也可能是舊版本多預留一份整部影片導致。本版只在確實需要 Chrome 暫存合併時預留整部空間，並使用 unlimitedStorage 解除一般擴充功能暫存配額／清除限制，但不會增加磁碟容量。若仍空間不足，請等待背景儲存完成、釋放 Chrome 所在磁碟空間或先將現有影片存出；不要清除 Chrome 資料或解除安裝擴充功能，以免失去未存片段。


## 安裝後自動啟用（v1.14.0）

原本 v1.13 及以前只能安裝檔案，Chrome 仍執行舊程式。本版加入安裝完成偵測與安全重載。完成安裝並等錄影、背景儲存和待救援影片全部處理完後，Chrome 會自動重新載入此擴充功能，並重開原本控制視窗。

首次從 v1.13 或以前升級仍需最後手動重新載入一次，才能啟用新機制；往後以 EXE 更新則不必。首次安裝仍需載入未封裝項目；ZIP 手動替換仍須手動重新載入。保持 Chrome 開啟且開發人員模式維持啟用；休眠／省電可能延後排程檢查。偵測只讀本機安裝完成標記，不會自動下載或略過安裝確認。


## 長影片合併加速（v1.15.0）

合併改用逐筆讀取影音封包，移除高速離線處理時不必要的滑動佇列；寫入批次由 1 MiB 提高為 8 MiB，減少磁碟呼叫。保留影音封包與時間順序、關鍵影格驗證、單一 MP4 輸出、背景儲存佇列及失敗救援；不重新壓縮，也不降低畫質或 FPS。

本機 Chrome 的約 104 MiB 合成影音測試，舊流程約 8 秒，新流程約 2 秒；這是特定測試資料與硬體的測量，實際長影片速度仍取決於資料量、硬碟與同時錄影負載。建議先設定儲存資料夾以直接輸出；未設定時 Chrome 下載仍有額外暫存與存檔步驟。
